# RefugiaPet organization repository

This repository owns the public organization profile and GitHub-wide collaboration files.

## Conventions

- Write product and community documentation in Spanish; use English for filenames, technical identifiers and commits.
- Do not claim customers, adoption results, metrics, security certifications or deployments that have not been verified.
- Never add credentials, private contact details or production configuration.
- Keep templates accessible, concise and useful for an early-stage SaaS team.

## Validation

Review Markdown links and Mermaid syntax before committing. Changes to templates must be reviewed for privacy and security implications.
